# Ekballo Sounds

Website oficial desenvolvido para a **Ekballo Sounds**, banda gospel de Curitiba/PR, com o objetivo de apresentar sua identidade, história, música, produtos, redes sociais e canais de contato.

O projeto foi desenvolvido com foco em uma experiência digital imersiva, utilizando uma estética contemporânea que combina elementos de música, tecnologia e identidade visual.

A interface utiliza vídeos, animações, efeitos de interação, navegação dinâmica e elementos inspirados em interfaces HUD para criar uma experiência diferente de um site institucional convencional.

## Visão geral

O website foi estruturado para funcionar como um hub digital da Ekballo Sounds, reunindo em uma única experiência:

* Apresentação da banda
* História e identidade
* Loja oficial
* Redes sociais
* Plataformas de música
* Solicitação de apresentações
* Formulário para eventos
* Informações de contato

## Seções

### Home

A página inicial apresenta a identidade visual da Ekballo Sounds através de uma composição tipográfica dividida em:

**EK / BA / LLO**

O Hero utiliza vídeo em background, elementos posicionados de forma dinâmica, informações complementares e animações para criar uma apresentação visual mais imersiva.

### Sobre a Ek

Seção dedicada à apresentação da banda, contendo informações sobre sua formação, integrantes, localização, gênero musical e propósito.

A seção também apresenta a origem do nome "Ekballo" e sua relação com a missão da banda.

### Loja Oficial

Área dedicada aos produtos da Ekballo Sounds.

A seção apresenta os produtos da banda através de vídeo, informações sobre as peças e uma chamada para contato.

### Redes Sociais

Centralização dos principais canais digitais da banda:

* Instagram
* YouTube
* Spotify
* Convite para apresentações

### Convide a EK

Área destinada à contratação da banda para eventos.

O usuário pode preencher um formulário informando:

* Nome
* E-mail
* Informações sobre o evento
* Mensagem

### Contato

Área destinada ao contato direto com a Ekballo Sounds, incluindo e-mail, Instagram e acesso ao formulário para eventos.

## Interações e efeitos

O projeto possui diversas interações desenvolvidas com JavaScript e CSS para tornar a navegação mais dinâmica.

Entre elas:

* Cursor personalizado com o logo da Ekballo
* Efeito de acompanhamento do cursor
* Elementos interativos ao passar o mouse
* Animações durante a navegação
* Efeitos de entrada e saída dos elementos
* Parallax em elementos selecionados
* Atualização dinâmica das informações do HUD
* Indicador de posição do cursor
* Indicador de progresso do scroll
* Identificação da seção atual
* Menu mobile interativo
* Marquee com movimento contínuo
* Atualização automática do ano no footer

## Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/FernandoMichelmann/Site-EK.git
```

### 2. Acesse o projeto

```bash
cd Site-EK
```

### 3. Acesse a pasta Front-end

```bash
cd FRONT
```

### 4. Execute o projeto

Abra o arquivo:

```text
EKBALLO.html
```

diretamente no navegador.

Não é necessário instalar dependências para executar a versão atual.

## Objetivo do projeto

O projeto foi desenvolvido como uma aplicação prática de desenvolvimento Front-end, utilizando uma identidade visual real para transformar conceitos de programação em uma experiência digital completa.

Além da implementação técnica, o desenvolvimento envolveu decisões de:

* UI Design
* UX
* Identidade visual
* Organização de conteúdo
* Responsividade
* Animação
* Interatividade
* Navegação
* Apresentação de mídia

O objetivo foi ir além de uma página estática e criar uma experiência que representasse visualmente a identidade e a proposta da Ekballo Sounds.
